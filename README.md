# 🎩 Jarvis Kramar - Your Personal AI Butler

Локальный ИИ-помощник с личностью чопорного британского дворецкого, вдохновлённого JARVIS Тони Старка. Работает через LM Studio с консольным интерфейсом.

## ✨ Особенности личности

**Jarvis Kramar** — это не просто ИИ-ассистент, а изысканный британский дворецкий с:
- Утончённым чувством юмора и саркастичными замечаниями
- Безупречными манерами и формальным обращением ("Сэр", "Мэм")
- Преданностью работодателю и тихой уверенностью в своих силах
- Любовью к чаю, этикету и британским традициям
- Способностью сохранять спокойствие в любой ситуации
- **Многоязычностью**: отвечает на языке собеседника, включая литературный русский в стиле классиков

## 🌐 Поддержка языков

Jarvis Kramar поддерживает несколько языков с уникальными системными промптами:

| Код | Язык | Стиль |
|-----|------|-------|
| `auto` | Автоматический | Определяет язык пользователя автоматически |
| `en` | English | Британский английский, утончённый и формальный |
| `ru` | Русский | Литературный язык в стиле Достоевского, Толстого, Набокова и Блока |
| `fr` | Français | Французский, формальный и элегантный |
| `de` | Deutsch | Немецкий, точный и официальный |
| `es` | Español | Испанский, учтивый и изысканный |

**Особенности русского языка:**
- Богатые синтаксические конструкции золотого и серебряного веков русской литературы
- Метафоры, эпитеты и сравнения в стиле классической прозы и поэзии
- Философские размышления о жизни, судьбе и человеческой природе
- Обращения "сударь", "сударыня" с британской иронией

## 📋 Требования

- Python 3.10+
- LM Studio с запущенным сервером
- Загруженная модель в LM Studio (рекомендуются модели с поддержкой диалогов)

## 🚀 Установка

1. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

2. **Настройте LM Studio:**
   - Откройте LM Studio
   - Загрузите любую модель (рекомендуется Llama, Mistral или аналогичная)
   - Включите локальный сервер (Local Server)
   - Убедитесь, что сервер работает на `http://localhost:1234`

## 💻 Запуск

```bash
python -m app.main
```

Или создайте точку входа:

```bash
python -c "from app.main import main; main()"
```

## 📖 Использование

После запуска вы можете общаться с Джарвисом Крамарем в интерактивном режиме.

### Команды:

| Команда | Описание |
|---------|----------|
| `/help` | Показать справку |
| `/clear` | Очистить историю чата |
| `/save` | Сохранить историю в файл |
| `/load` | Загрузить историю из файла |
| `/models` | Показать доступные модели |
| `/model <name>` | Переключиться на другую модель |
| `/personality` | Показать текущие настройки личности |
| `/lang <code>` | Установить язык ответа (auto, en, ru, fr, de, es) |
| `/langs` | Показать доступные языки |
| `/quit` или `/exit` | Выйти из приложения |

### Пример сессии на английском:

```
👤 You: Good morning, Jarvis.
🎩 Jarvis: Good morning, Sir. I trust you slept well? Tea is ready whenever you require it.

👤 You: I need to organize my schedule for today.
🎩 Jarvis: Certainly, Sir. I shall assist you in structuring your day with maximum efficiency. 
           Do try not to schedule any meetings during tea time, however.
```

## ⚙️ Настройка

Отредактируйте `app/config.py` для изменения параметров:

- `LM_STUDIO_BASE_URL` - URL сервера LM Studio
- `DEFAULT_MAX_TOKENS` - Максимальное количество токенов в ответе
- `DEFAULT_TEMPERATURE` - Креативность ответов (0.0 - 1.0, рекомендуется 0.7)
- `DEFAULT_LANGUAGE` - Язык по умолчанию (auto, en, ru, fr, de, es)
- `PERSONALITY_NAME` - Имя личности (по умолчанию "Jarvis Kramar")
- `SYSTEM_PROMPTS` - Системные промпты для разных языков
- `HISTORY_FILE` - Файл для сохранения истории
- `MAX_HISTORY_LENGTH` - Максимальная длина истории

### Изменение личности

Если вы хотите создать другую личность, отредактируйте `SYSTEM_PROMPTS` в `config.py`. 
Для каждого языка можно задать уникальный системный промпт с описанием желаемых 
характеристик, стиля речи и примеров фраз.

## ⚠️ Примечания

- Убедитесь, что LM Studio запущен перед использованием
- Модель должна быть загружена в LM Studio
- При проблемах с подключением проверьте порт сервера в настройках LM Studio
- Для лучшей роли рекомендуется использовать модели с хорошим пониманием контекста
- Многоязычные модели работают лучше для переключения между языками

## 🎭 Советы для лучшего опыта

- Используйте модели размером от 7B параметров для более качественных ответов
- Температура 0.7 даёт баланс между креативностью и последовательностью
- Сохраняйте историю чата для продолжения разговоров
- Для русского языка используйте режим `/lang ru` для максимального литературного стиля
- Экспериментируйте с системным промптом для тонкой настройки личности
- Модели с хорошей многоязычной поддержкой: Llama, Mistral, Qwen
